# ЧистоДом — Cleaning Service Landing Page

Адаптивный одностраничный сайт для вымышленной клининговой компании «ЧистоДом».

Проект разработан в качестве демонстрационной работы для портфолио веб-разработчика.

## 🌐 Демо

**[Посмотреть работающий сайт](https://dmitriy-veremyanin.github.io/chistodom/)**

## 📌 О проекте

Цель проекта — создать современный, понятный и удобный сайт для небольшой компании, предоставляющей услуги уборки.

Сайт помогает посетителю ознакомиться с услугами, посмотреть ориентировочные цены и перейти к форме заявки.

## ✨ Возможности

- Адаптивная вёрстка для мобильных и настольных устройств
- Современный интерфейс с зелёными акцентами
- Карточки услуг с изображениями
- Раздел преимуществ компании
- Блок с ориентировочными ценами
- Мобильное меню
- Демонстрационная форма заявки с проверкой полей
- Плавная навигация между разделами

## 🛠 Технологии

- HTML5 — структура страницы
- CSS3 — стили, сетки и адаптивный дизайн
- JavaScript — интерактивность
- GitHub Pages — бесплатная публикация

## 🚀 Запуск проекта

1. Скачайте репозиторий.
2. Откройте папку проекта.
3. Запустите файл `index.html` в браузере.

Для просмотра опубликованной версии перейдите по ссылке выше.

## ⚠️ Примечание

«ЧистоДом» — вымышленная компания. Сайт создан для демонстрации навыков веб-разработки.

Форма заявки работает только в демонстрационном режиме: данные не отправляются на сервер и не сохраняются.
